# Clean & Uncluttered UX Rule (Always Enforced)

1. **Zero Clutter / Zero Visual Overload on Login:**
   - Never crowd the home feed, navigation bar, sidebars, or floating docks with unsolicited popups, stacked banners, or multi-panel blocks when a user logs in.
   - Floating messaging docks must stay collapsed by default on login.
2. **Progressive Disclosure (Show Details Only on Click):**
   - Keep default views focused on the primary task.
   - Multi-field setup forms, AI explanations, and secondary tools must live inside their dedicated tab, modal, or expandable drawer and open only when the user explicitly clicks a button or tab (e.g., `Get started` or `🔔 Set Up Job Alerts`).
3. **Concise Copy & Minimal Actions:**
   - Avoid redundant buttons, duplicate banners, or noisy badges. Every card should have one clear purpose and one clear primary action.
